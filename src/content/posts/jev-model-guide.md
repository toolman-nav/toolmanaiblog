最近AI圈火了个很怪的模型，叫 **Jev**。

火到什么程度？上线24小时，近13%的付费团队就接入了，创下AI史上最快的采用纪录，Vercel、Cloudflare这些大厂第一时间跟进。

它的卖点相当反直觉：**不会聊天、不会写文章、不会写代码，连一句完整的话都说不出来。**

你给它一段文字，它只回你几个数字和标签——"96%紧急""分类：账单问题""愤怒程度：3.0/4"。

就这么个"哑巴"，现在注册还**送约1.2亿token的额度**。今天这篇讲清：它是啥、能干嘛、怎么白嫖上手。

## 一、Jev是什么？一个只会"做选择题"的AI

一句话：**普通大模型擅长写长篇大论，Jev擅长一锤定音。**

它只接受三种问题，每种都直接返回结果和概率：

| 问题类型 | 干什么 | 生活化例子 |
| --- | --- | --- |
| Choice（选择） | 从你给的选项里挑一个 | 这封客服邮件该转给哪个部门？ |
| Score（打分） | 给一个连续分数 | 客户愤怒程度1-4分，打几分？ |
| Noul（判断） | 是/非判断，返回0到1的概率 | 这笔订单是不是盗刷？ |

**为什么又快又便宜？**普通大模型是一个字一个字往外蹦的，输出越长越慢越贵；Jev的答案空间是预先定死的——选项就那么几个，概率一算就出，官方数据延迟只要70-500毫秒，比最快的前沿大模型快上百倍，输入每百万token才0.042美元，**输出直接免费**。

名厂背书也有：第三方测过，Jev的判断和Claude Fable 5.1的一致率高达91.5%，但成本只有后者的万分之五。垃圾邮件分类零样本准确率98.64%。

顺便说个冷知识：Jev的名字来自19世纪经济学家的"杰文斯悖论"——蒸汽机越省煤，全英国煤消耗反而越大，因为便宜到以前用不起的行当都用起了。TypeSafe取这个名字的意思很直白：**等AI判断便宜到可以忽略不计，它就会被塞进软件的每一个角落。**

## 二、从0开始用上Jev

### Step 1：注册领额度

1. 打开TypeSafe官网（typesafe.ai），注册账号——**无需绑卡，直接送约1.2亿token**；
2. 在控制台创建一个API Key，复制保存好。

### Step 2：最省事的玩法——装官方Skill（推荐小白）

直接调API要写代码，小白很容易劝退。更省事的办法：**把官方Skill装进Codex或Claude Code，让它帮你组织请求**。

先划重点：**Codex和Claude Code是两个工具，安装命令别混着用**。下面按你正在用的工具选一条路就行，不用全装。

**用Claude Code的：**

打开终端，依次执行下面两条命令：

```bash
claude plugin marketplace add typesafe-ai/skills
claude plugin install typesafe@typesafe-ai
```

**用Codex或其他Agent的：**

先确认电脑装好了Node.js和npm，再在终端执行：

```bash
npx skills add typesafe-ai/skills --skill typesafe-ai -g
```

按提示选择你使用的Agent；用Codex就选Codex。这里的`-g`表示全局安装，不加则默认装到当前项目。装好后重启Agent，让它加载技能。

没装过Codex的先看这篇补课：[OpenAI Codex国内保姆级教程](https://toolmanai.com/blog/codex-china-guide-2026/)。安装方法也可以对照[TypeSafe官方说明](https://docs.typesafe.ai/agent-skill)。

**还有一步别漏：配API Key。**

Skill相当于使用说明书，API Key才是调用凭证。先到[TypeSafe控制台](https://console.typesafe.ai/)创建Key，再把它放进名为`TYPESAFE_API_KEY`的环境变量。不要把真实Key发到聊天里或写进文章代码。

Windows PowerShell用户，在终端执行下面这行，然后在本地提示框输入Key：

```powershell
$env:TYPESAFE_API_KEY = Read-Host "输入你的 TypeSafe API Key（仅在本地输入）"
```

macOS用户（默认zsh终端）执行：

```zsh
read -rs 'TYPESAFE_API_KEY?输入你的 TypeSafe API Key：'
export TYPESAFE_API_KEY
echo
```

Linux用户（Bash终端）执行：

```bash
read -rs -p '输入你的 TypeSafe API Key：' TYPESAFE_API_KEY
export TYPESAFE_API_KEY
echo
```

这些设置只对当前终端及从它启动的程序生效。接着**在同一个终端启动`codex`或`claude`**。如果用的是桌面App，在另一个终端设变量不一定能传进去，需要按客户端支持的方式配置运行环境，再完全退出重开。

**最后跑一次小测试，别只看“安装成功”。**

把下面这段发给Agent：

```text
请使用TypeSafe技能，从环境变量TYPESAFE_API_KEY读取密钥，不要输出密钥。
实际调用Jev一次，判断这条留言是否紧急，以及该交给技术、账单还是销售部门：
“付款成功了，但账号仍未开通，今天下午要用，请尽快帮我处理。”
请展示API返回的判断结果和概率。如果缺少密钥、网络不通或调用失败，请说明原因，不要模拟结果。
```

拿到实际返回结果，才算真正跑通。提示没找到技能，就检查安装时是否选对Agent并重启；认证失败就核对Key是否有效、Agent能否读取变量；额度或网络报错则按提示处理。测试会使用你的API额度，成功一次就够了。


### Step 3：进阶——API/CLI直调（可选）

开发者可以直接按官方文档调API（模型别名 `jev-latest`），也支持Kollab的CLI方式。写脚本、接流水线的场景再研究，普通用户跳过这步完全不影响。

## 三、普通人能拿它干嘛？

别被"API模型"吓住，围绕几个真实案例说人话：

**1. 收藏夹救星：资料自动分类打标。**

浏览器收藏夹、Notion页面、微信文件存了上千条，"记得存过但找不到"？让Jev按你定的分类批量打标。有开发者拿它给论文自动分类，一篇256毫秒，1000篇成本不到1毛钱美元级别——你的收藏夹整理工程，成本几乎可以忽略。

**2. 发文前先"验货"。**

写完社媒帖子/文章，让Jev预判：读者会不会点？能不能看完？愿不愿转发？有创作者做了个"写草稿→打分→重写"的循环，发布前就把质量拉一遍，不再纯靠感觉。

**3. 省钱路由器：让它决定调谁。**

这是最有"基建"味的玩法：给AI工作流加一道Jev判断——简单问题路由给便宜模型，硬仗才给最贵的。很多任务根本不需要最贵的大模型，这一道分流能省下大把token。

其他脑洞还有：7.1秒自动在网页里查完航班（单次成本0.0039美元）、让Jev实时操作马里奥跳跃、给客服工单自动分级。全球网友已经开源了几百个项目，搜"Jev"能看到一堆。

## 四、避坑指南（4条，官方FAQ提炼）

1. **中文判断准确率低于英文**。官方明确说了中日韩（CJK）语言支持但准确率不如英文——重要的判断任务，试试先把内容翻译成英文再让它判，或英文描述判断标准。

2. **"零幻觉"不等于不犯错**。它绝不会编造选项之外的答案、绝不会输出格式错误（这就是"零幻觉"的含义），但**完全可能在一堆选项里选错**。它的置信度分数也没经过严格校准，只能当相对参考——高风险决策记得抽查。

3. **只吃纯文本，最多8万字符**。图片、音频、视频一概不收，想判断这些内容，先用其他模型转成文字（比如截图OCR、录音转写）再喂给它。

4. **它不解释理由**。问它"为什么选这个"，没有回答，只有数字。需要给出依据的决策（比如拒信、审批），别全交给它，它适合当参谋，不适合当法官。
