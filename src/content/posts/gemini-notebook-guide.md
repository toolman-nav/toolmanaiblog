## 一、notebooklm是干嘛的？和ChatGPT有啥区别

一句话：**你喂资料，它干活。**

普通AI是"啥都懂一点"，但来源不可控，容易一本正经地瞎编。Gemini Notebook反着来——**它只基于你上传的资料回答**，答案里每个关键句都带引用标注，点一下直接跳回原文对应位置，不会出现无事实瞎编的情况。

| | ChatGPT这类通用AI | Gemini Notebook |
| --- | --- | --- |
| 知识来源 | 全网训练数据，不可控 | 只用你上传的资料 |
| 幻觉问题 | 会编（尤其冷门细节） | 查不到就说查不到 |
| 答案可验证 | 难溯源 | 每句话带引用，点击回原文 |
| 适合场景 | 闲聊、创意、通用问答 | 论文、报告、长资料精读 |

一句话总结：**要它"懂你给的资料"，用它；要它"啥都知道"，用ChatGPT。**

## 三、5分钟上手

### Step 1：新建笔记本

打开网站，用谷歌账号登录，点**"新建笔记本"（+ Create New）**，就得到一个空工作区。

### Step 2：喂资料（灵魂步骤）

点来源区的**"添加"（Add）**，支持的格式多到离谱：

| 类型 | 格式 | 注意 |
| --- | --- | --- |
| 文档 | PDF、Word、TXT、Markdown、ePub | 单个来源最大50万词/200MB |
| 网页链接 | 公开网页 | **只抓文字**，图片和登录墙内容抓不到 |
| YouTube | 公开视频链接 | 自动提取字幕，等于白嫖视频文稿 |
| 表格 | Google Sheets、CSV | |
| 音频 | MP3、WAV | 录音也能分析 |
| 云端 | Google Drive文件、Gemini对话 | 定时自动同步 |

新手第一次玩，建议传一份PDF+一个YouTube链接感受一下。

### Step 3：提问，学会点引用

在右侧对话框发问。答案会自动生成，**关键句后面跟着引用角标，点一下直达原文位置**——这是它和ChatGPT最大的区别，也是"不瞎编"的底气。

第一次不知道问啥，它自动生成了推荐问题，点着玩就行。

### Step 4：换个问法，质量翻倍

别问"给我讲讲这份资料"——太浅。试试这些句式：

* "资料3里关于X的主要论点是什么？"
* "对比资料1和资料4在Y问题上的观点差异"
* "把所有资料里提到Z的例子全部列出来"

## 四、杀手锏：一键把资料变播客

这是Gemini Notebook最出圈的功能，也是很多人入坑的理由。

在**Studio面板**点**"音频概览"（Audio Overview）**，可以把资料生成适合收听的音频。**深入探讨（Deep Dive）**是双人对谈；**简报（The Brief）**是单人快速概述，此外还有评论和辩论等模式。时长会随模式、资料和可选设置变化，并非固定10—20分钟，生成后可下载收听。

可用模式和语言设置以你的界面为准，具体见[官方音频概览说明](https://support.google.com/gemininotebook/answer/16212820?hl=en)。

三个实用技巧：

1. **生成前先看账号里的剩余额度**。个人账号正逐步改用每5小时刷新的计算量额度，不宜再按“每天3次”估算。想调整内容，用**Customize（自定义）**先写清楚角度（比如“重点讲第二章，面向初学者解释”），减少反复生成；
2. 生成要几分钟，**别频繁刷新页面**，等它跑完；
3. 中文资料照样能生成中文播客，效果可以。

顺便一提，Studio面板还有**思维导图、学习指南、闪卡、测验、时间线、视频概览**等一堆一键输出，学生党复习、打工人做汇报资料，点几下全齐。

## 五、避坑指南：新手注意这4点

1. **别无脑堆资料**。它不是百度网盘，30个精选来源的笔记本，效果吊打300个乱塞的大杂烩——输出质量完全取决于你喂了什么。

2. **上传成功≠解析正确**。重要结论**一定点开引用回看原文**；来源加进来后先看一眼自动生成的摘要靠不靠谱，再开始正式提问。

3. **网页/视频链接抓不到内容时**：网页要登录、是付费墙内容、视频没字幕——都会导入失败。别反复重试，把内容另存成PDF直接上传，药到病除。

4. **删除无法恢复**。误删的笔记本Google明确说没有找回渠道，重要笔记本勤备份。
