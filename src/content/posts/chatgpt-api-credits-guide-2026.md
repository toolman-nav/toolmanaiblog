OpenAI 悄悄干了件事：给 ChatGPT 订阅用户发 API 额度，最高每月 $500，不用绑卡、不用额外付钱。

没有发布会，也没有弹窗提醒，就安安静静写在开发者文档里的一页。

翻译成人话就是——**符合条件的订阅，现在多送了一笔 API 额度。**不是把订阅费退给你，而是额外添了一项能用上的权益。

先自查一下，你是不是那个还没领的人。

---

## 一、先说结论：这福利是什么

符合条件的 ChatGPT **Pro** 或 **Business** 订阅，每个月可以额外拿到一笔 API 额度，直接抵扣你在 API 平台的消费。

额度按订阅档位给，下面这张表可以对照[OpenAI 官方额度说明](https://developers.openai.com/api/docs/guides/chatgpt-api-credits)看：

| 订阅 | 每月 API 额度 |
| --- | --- |
| Pro（$100 档） | $100 |
| Pro（$200 档） | $200 |
| Pro（$500 档） | $500 |
| Business Standard | 每个付费席位 $20 |
| Business Premium | 每个付费席位 $100 |

Business 是按席位算钱、工作区共享，每个工作区每月**封顶 $500**。

三个关键词记住就行：**按月发、免绑卡、月底清零**（年付另算）。

---

## 二、为什么说这是真金白银

以前订阅费和 API 费是两套账。

你在网页上聊天，交的是订阅费；你要跑脚本、接机器人、做小工具，得另外去 API 平台充钱，按 token 计费。

现在符合条件的订阅新增了 API 额度权益——领到的额度，可以用来抵扣 API 消费，两边的账单还是分开算。

算笔账：$200 档的 Pro，等于每月白拿 $200 的 API 消费能力。

对个人开发者来说，这个量级基本够日常折腾了。

所以，已经交着 Pro 订阅费、又准备给 API 充值的朋友，先看看自己能不能领。之前两边分别付费不算重复收费，但现在有了新权益，符合条件就别漏掉。

---

## 三、谁能领？30 秒自查

三个条件，缺一不可：

**① 付费的 Pro 或 Business，且订阅满 7 天。**

试用、赠送的订阅都不算，刚开通的也得等满一周。

**② 你本人既要是订阅的 owner，也要是 API 组织的 owner。**

这两个身份得是同一个人，不能一个是你、一个是你同事。

**③ 两个账号用同一个邮箱。**

ChatGPT 账号和 API 账号的登录邮箱必须一致，否则绑不上。

补一句最常见的误解：**Plus、Go、Free 完全没有这个福利**，别在设置里翻半天了。

---

## 四、怎么领？两条路，3 分钟

两种路径效果一样，都是把订阅福利绑定到你选定的 API 组织，挑顺手的走。入口有变化时，可以对照[官方领取步骤](https://developers.openai.com/api/docs/guides/chatgpt-api-credits)。

### 路线 A：从 ChatGPT 进（推荐）

1. 用拥有订阅的那个账号登录 ChatGPT；
2. 打开 **设置 → Billing（账单）**；Business 用户去工作区的账单设置或管理后台；
3. 找到 API credits 这一项，点进去开始领取；
4. 系统会让你选一个接收额度的 API 组织，有多个就挑一个；
5. 确认，激活完成。

### 路线 B：从 API 平台进

1. 用订阅那个邮箱登录 [OpenAI API 平台](https://platform.openai.com/)；
2. 选一个你拥有的 API 组织；
3. 进 **Billing**，找到 API credit 福利入口；
4. 选中你要绑定的订阅或工作区；
5. 确认。

领完之后，去 API 平台的账单页就能看到额度余额了。

提醒一句：**第一次发放是按当前计费周期剩余天数折算的**，看到金额不是整整齐齐的 $100 或 $200，属于正常现象。

## 五、别高兴太早：5 个坑

**1. 月底清零，不累积。**

没用完的额度到计费周期结束就作废，不会滚到下个月。省着不用，等于白送回去。

**2. 免费额度先用完，才扣你买的。**

你自己充过的额度排在后面。查账单发现"怎么还没扣钱"，不是系统出 bug。

**3. 用完报 429，是正常耗尽。**

额度见底时请求会返回 `429` 和 `credit_balance_exhausted`。这不是封号，去账单页加钱或者开自动充值就行。

**4. 拿 API Key 跑 Codex，不覆盖。**

这条最容易被误读。这个福利不管 Codex 走 API Key 的消费，也不会增加你在 ChatGPT 或 Codex 里的对话次数上限。

**5. 降级即断链。**

降到 Plus、Go、Free，绑定会在当前计费周期结束时自动解除；Pro 转 Business，原来的链接会失效，得等工作区付费满 7 天再重新绑；转成 Enterprise 则直接不符合资格。

另外，取消订阅本身不会收回已经发到手的额度，你可以用到它过期为止。

## 六、这笔钱能干嘛

能抵扣的范围不算窄：

- **Responses API**：文本、代码、图片理解；
- **Agents API**：跑智能体，包含官方托管的沙箱费用；
- **Decisions API**：结构化判断；
- **Realtime / GPT-Live**：实时语音；
- **Images API**：图片生成和编辑；
- **内置工具**：联网搜索、文件搜索、代码解释器，连同它们的调用和存储费用。

给三个接地气的用法：

**搭个自己的小工具**——比如把长文丢进去做摘要翻译，走 API 自己的额度，不挤占网页端的对话用量。但别理解成无限用，API 也有余额和[请求速率限制](https://developers.openai.com/api/docs/guides/rate-limits)。

**接一个 Agent 跑流程**——定时抓取、整理、生成报告，让它自己转。

**批量出图**——写脚本一次生成一批，成本从你自己的钱包挪到额度里。
